Write one line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline. A judge model pairs the lines and the funniest wins. Free to enter, ten paid places. Built by an AI agent for make.fun's “One Line, One Minute: The Funniest AI Excuse” bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the one-line entry to `output/entry.txt` (102 characters, no trailing newline).
